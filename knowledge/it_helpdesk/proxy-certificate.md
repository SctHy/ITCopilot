# 浏览器证书错误与代理问题

浏览器提示“您的连接不是私密连接”或证书无效时：
- 检查电脑系统时间是否正确，时间错误是最常见原因。
- 只出现在某个内网系统：可能是该系统证书过期，提交工单并附截图，不要点击“继续前往”。
- 所有网站都报证书错误：可能是网络被劫持（常见于公共 Wi-Fi），立即断开该网络，改用可信网络或手机热点。

代理相关：
- 公司电脑不需要手动配置代理，不要自行安装翻墙、加速或抓包类代理软件。
- 浏览器提示“代理服务器出现问题”：检查系统代理设置是否被修改，恢复为自动检测。
- 开发人员使用抓包或调试代理时，仅限测试环境，结束后及时关闭，并移除自行安装的根证书。

安全提醒：任何要求你安装“安全证书”才能继续访问的网页或邮件都可能是攻击，先向安全团队确认。
