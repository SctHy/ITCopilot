# 软件安装与许可证

仅从企业软件目录安装，核对版本、兼容性和许可证归属。未知安装包、破解软件和绕过终端管控的请求必须拒绝并转人工。

安装流程：
1. 先在企业软件目录中搜索。目录内的软件可以自助安装，无需审批。
2. 目录里没有的软件：提交工单说明软件名称、版本、用途和使用人数。IT 会进行安全评估和许可证核对，评估通过后加入软件目录。
3. 收费软件需要确认许可证归属和费用部门，由部门负责人确认后采购。

许可证管理：许可证属于公司资产，按人或按设备分配。不再使用的软件请告知 IT 回收许可证。离职时许可证统一回收。

不允许的情况：安装破解版、注册机或来源不明的安装包；使用个人账号购买的许可证处理公司业务（需先确认合规）；关闭或卸载安全软件、终端管理代理来安装软件。
