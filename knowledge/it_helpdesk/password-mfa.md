# 密码重置与 MFA

密码重置必须由员工本人通过企业身份平台发起并完成 MFA 验证。服务台只能创建待审批的重置请求，不在聊天中接收或回显密码、OTP 验证码、恢复码或私钥。任何自称 IT 人员、通过聊天或电话索要验证码的行为都是诈骗，请立即上报安全团队。

自助重置步骤：
1. 打开企业身份平台登录页，点击“忘记密码”。
2. 输入员工账号，用已绑定的 MFA 设备完成验证。
3. 设置新密码：至少 12 位，包含大小写字母、数字和符号，不能与最近 5 次密码相同，不要包含姓名、工号或公司名。
4. 修改后，手机邮箱、VPN 客户端、Wi-Fi 等保存了旧密码的地方需要重新登录，否则可能反复输错导致账号锁定。

无法自助时（例如 MFA 设备丢失）：在服务台提交密码重置申请，提供员工编号，审批通过后由系统执行；真实企业账号仍需身份平台核验本人。
