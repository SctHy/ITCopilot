# 浏览器常见问题

企业推荐使用最新版 Chrome 或 Edge，浏览器由终端管理统一更新。

- 页面显示异常、加载不全：先强制刷新（Windows 按 Ctrl + F5，macOS 按 Command + Shift + R）；仍不正常时清除该网站的缓存和 Cookie。
- 内网系统登录后又跳回登录页：清除该站点 Cookie，检查是否禁用了第三方 Cookie，确认系统时间正确。
- 浏览器很卡：关闭不用的标签页；在扩展程序管理中停用不认识或不需要的扩展。
- 弹窗广告、主页被篡改：可能安装了恶意扩展或软件，删除可疑扩展并提交工单检查电脑。

扩展程序安全：只从官方商店安装业务需要的扩展；不要安装要求“读取和更改所有网站数据”的不明扩展。不要让浏览器保存企业账号密码到非企业管理的密码管理器中。
