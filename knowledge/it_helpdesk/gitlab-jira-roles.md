# GitLab 与 Jira 角色说明

GitLab：
- 只读（readonly）：浏览代码、Issue 和 Merge Request，不能推送代码。适合代码评审旁听、排查问题时查看实现。
- 报告者（reporter）：在只读基础上可以创建和评论 Issue、查看 CI 结果。适合测试、产品和支持人员。
- 开发者（developer）：可以推送分支、创建 Merge Request、运行流水线。受保护分支仍需按项目规则合并。开发者权限需要两名审批人批准，最长 72 小时。

Jira：
- 只读：查看项目、看板和工单。
- 报告者：创建和评论工单。
- 开发者：编辑、流转工单和维护看板。

如何选择：只是看代码或看工单，选只读；需要提交问题，选报告者；需要改代码或流转工单，才选开发者。申请时写清楚具体项目和要完成的工作，审批人会据此判断。

提示：“读”“只读”“read”都会被识别为只读角色。管理员、Maintainer、Owner 不提供线上申请。
