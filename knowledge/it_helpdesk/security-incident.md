# 疑似中毒或安全事件

可能是安全事件的迹象：安全软件报警；文件被加密、后缀被改并出现勒索说明；电脑出现陌生程序或账户；收到不是自己发起的登录提醒或 MFA 推送；账号发出了自己没发的邮件。

发现后立即：
1. 断开网络（拔网线、关闭 Wi-Fi），但不要关机，以便保留调查线索。
2. 不要自行删除文件、运行清理工具或重装系统。
3. 立即联系安全团队并提交 P1 或 P2 工单，说明现象、时间和你做过的操作。
4. 如怀疑账号被盗用，在另一台可信设备上修改企业密码。

疑似勒索、多台电脑同时异常或涉及客户数据时，按 P1 处理。安全团队会远程隔离设备并指导后续处置，期间 IT 会安排备用机。
