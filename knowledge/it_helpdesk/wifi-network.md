# Wi-Fi 与网络排障

收集地点、设备、SSID、错误提示和时间窗口，优先执行只读的 DNS、路由和服务状态检查。不要修改网络策略；影响多人时升级网络团队。

办公网络说明：员工设备连接企业 Wi-Fi，使用企业账号认证；访客和个人设备请使用访客 Wi-Fi，不能接入办公网络。

员工自查步骤：
1. 关闭再打开 Wi-Fi，或“忘记此网络”后重新连接。
2. 改过企业密码后，Wi-Fi 也需要用新密码重新认证。
3. 确认其他同事在同一位置是否正常：只有自己有问题多为设备问题，多人有问题多为网络故障。
4. 能连上但网速很慢：换个位置靠近无线接入点，或改用有线网络对比。
5. 提示“已连接，无互联网”：记录 SSID 和位置，检查是否获取到 IP 地址。

需要提供的信息：具体楼层或会议室、SSID、设备型号与系统、错误截图、开始时间、影响范围。
