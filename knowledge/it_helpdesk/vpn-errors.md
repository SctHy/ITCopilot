# VPN 常见报错与处理

- 认证失败 / 用户名或密码错误：确认账号未锁定、最近是否改过密码；客户端里可能保存了旧密码，清除后重新输入。连续失败会触发锁定。
- MFA 推送收不到：检查手机网络和验证器 App 通知权限；可改用验证器里的动态码。
- 证书错误 / 证书不受信任：检查系统时间；确认连接的是企业公布的 VPN 地址，不要点“仍然继续”。地址正确仍报错，提交工单。
- 连接超时：当前网络可能屏蔽了 VPN 端口，换网络（如手机热点）再试；同时关注 IT 服务状态公告是否有 VPN 故障。
- 已连接但网页打不开：多为 DNS 问题，见“DNS 与内网域名解析”。
- 频繁自动断开：检查是否开启了系统省电或休眠；Wi-Fi 信号弱时优先使用有线网络。
- 提示无权限 / 账号不在允许列表：VPN 权限未开通或已过期，提交 VPN 只读权限申请。

多人同时出现相同报错时，可能是服务端故障，请提交 P1 或 P2 工单并注明影响人数。
