# macOS 常见问题

- 应用无响应：按 Command + Option + Esc 强制退出该应用。
- 整机卡死：长按电源键强制关机后重新开机。
- 系统更新：企业会统一推送经过验证的系统版本，请在提示时尽快安装；不要自行安装 Beta 版本。
- 提示“无法打开，因为无法验证开发者”：说明软件不是来自可信来源，请改从企业软件目录安装，不要在安全设置中强行放行。
- 磁盘空间不足：在“系统设置 > 通用 > 储存空间”查看占用，清理下载目录和大文件；不要删除系统和管理配置文件。
- 外接显示器不识别：重新插拔线缆、换接口，在“显示器”设置中检测显示器，确认转接头是否支持对应分辨率。
- 钥匙串反复要求输入密码：多发生在修改企业密码后，提交工单由 IT 协助处理，不要在聊天中发送密码。

企业 Mac 安装了管理描述文件，请勿删除，否则会失去 Wi-Fi、VPN 等配置。
