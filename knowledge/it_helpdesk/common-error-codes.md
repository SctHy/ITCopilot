# 常见错误码速查

- 401 认证失败：确认身份平台（SSO）状态正常；检查电脑系统时间是否准确、客户端是否为最新版本；重新登录一次。仍失败时提交工单并附上发生时间。
- 403 权限不足：账号已登录但没有该系统或资源的权限。确认需要的最小权限后提交权限申请，审批通过前无法访问；不要借用他人账号。
- 500 服务端处理异常：问题在服务端，不是本机设置。记录页面上的 request_id 和发生时间，稍后重试；多人同时出现时提交 P1 或 P2 工单并注明影响范围。
- VPN-691 VPN 身份认证或连接失败：确认账号未被锁定、最近是否改过密码（客户端可能保存了旧密码）；检查系统时间、DNS 设置和 VPN 客户端版本。详见“VPN 常见报错与处理”。

不在此表中的错误码，请补充完整报错内容、发生时间和运行环境后提交工单。
