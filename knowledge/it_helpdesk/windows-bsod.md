# Windows 蓝屏与异常重启

遇到蓝屏时，用手机拍下屏幕上的停止代码（例如 MEMORY_MANAGEMENT、IRQL_NOT_LESS_OR_EQUAL）和发生时间，这是诊断的关键信息。

员工可以做的：
1. 回想蓝屏前的操作：是否刚安装驱动、软件或系统更新，是否接入了新外设。
2. 拔掉非必要外设（扩展坞、U 盘、外接显卡坞）后重启观察。
3. 确认系统更新已全部安装完成。
4. 偶发一次且之后正常，可以继续观察；同一天反复出现或无法进入系统，立即提交工单。

不要做的：不要自行下载来路不明的驱动更新工具、“蓝屏修复”软件；不要自行重装系统，以免丢失数据和企业管理配置。

工单信息：设备资产编号、停止代码、发生次数和时间、蓝屏前的操作、系统版本。无法开机时注明，IT 会安排备用机。
