# 0041 工作流进程与事务边界

API 处理审批，Worker 领取并执行动作、巡检授权和清理过期数据。两个进程共享数据库。审批、授权台账和动作队列复用 SQLAlchemy Core 事务，异步调用通过 psycopg 或 aiosqlite 执行数据库 I/O。

审批通过与动作入队在同一事务中提交。PostgreSQL 的 NOTIFY 唤醒独立 LISTEN 连接，Worker 通过 SKIP LOCKED 领取动作。资源锁、租约和版本校验保护相同资源的串行执行。周期轮询负责未来到期动作及断线补偿。SQLite 在提交后唤醒本进程监听者，独立进程通过轮询发现工作。

收到终止信号后就绪探针返回 503。Worker 停止领取，等待在途动作提交。宽限期结束时，已经开始外部调用的动作按未知结果交还队列，接手者先观察目标系统。API 在释放依赖前等待在途请求和 SSE。
