## 环境与可复现性

- 在 main 的当前工作区验证；原有改动保留，按工作包整理提交。
- PostgreSQL 使用独立 pgvector/PostgreSQL 18 测试容器，每项测试单独 schema；没有连接生产数据库。
- Keycloak 26.8 与 Gitea 1.27 使用本轮创建的独立容器与演示账户。
- 真实模型应用评测使用临时 SQLite 台账和专用 Redis；每个用例、每次重复均重新建业务台账。样本为仓库编写的业务场景，不是线上流量。
- 性能基线来自此前保留的 WP6 前源码快照，优化后来自本轮工作区；原始报告保留源码/数据集哈希、路由配置及时间。两组共享同一模型服务商，存在外部负载、缓存、并行评测和随机性影响，结果不能用于因果推断。源码快照间还包含策略审计原子性、Badcase 生命周期和反馈校验修复，不能将测量差异全部归因于截止时间。
- 原始评测保存在 `evaluation/reports/acceptance_2026-11-13/`；候选资格摘要保存在 `evaluation/reports/routing/`，后者纳入 Git 供 CI 使用。

## 复查修复（2026-11-13）

验收后的代码复查复现了以下问题，已修复并补充回归测试，详见 CHANGELOG「验收复查修复」：

| 问题 | 影响 | 修复 |
|---|---|---|
| 有意保留的外部权限修改让回收永远停在人工复核 | 同一人同一系统之后的已批准申请永久排队（已用测试复现） | 管理员人工结案 `POST /approvals/{id}/resolve`（ADR 0028） |
| 脱敏把 password/otp/token 后的普通英文单词当秘密 | 英文回复对用户显示 `[REDACTED]`，记忆被改写 | 弱写法要求含数字或符号（ADR 0032） |
| 回滚后已粘住的会话和事项继续使用被撤下版本 | 自动回滚对已有会话无效（计划原设计错误） | 只沿用仍被服务的版本（ADR 0033） |
| 路由配置热加载改错导致全部模型调用失败 | 一处笔误影响所有副本 | 保留上一份已校验配置并告警（ADR 0030） |
| 路由对所有模型发送 DeepSeek 专有思考参数 | 接入其他厂商时请求可能被拒 | 模型声明 `thinking_api`（ADR 0030） |

复查修复后 SQLite 全量与前端重新运行；本机没有 Docker，PostgreSQL 契约测试由 CI 运行，本轮未在本地重跑。路由仍只配置了一个模型，故障切换、延迟切换与合规过滤只有离线测试覆盖。
