# 数据脱敏测试说明（2026-11-14）

本地识别采用 AstrLink Guard v0.1.3 INT8 模型结合正则表达式规则（置信度阈值 0.8，纯 CPU 推理）。以下为最后保留的 v3 对比测试数据，用于记录当时的识别表现，不代表线上生产环境的实际分布。测试共覆盖 28,583 篇文档，分别统计“敏感内容是否完整遮盖”以及“类型和边界是否完全命中”。

- **已知局限**：中文测试集新增了 1,470 个完整遮盖且未丢失原有覆盖；但在英文和金融集上仍有 14 个实体出现漏检回退（其中 6 个真实姓名被误判为地址后过滤），因此不能宣称零回退。中文测试集缺少纯正常文本样本，纯正常中文的误报率尚未测得。
- **数据口径提醒**：NVIDIA 英文新增集首次测试后曾用于排查修复，因此最终指标属于回归测试结果，不再算作独立盲测集。
- **工具参数还原测试**：两种模式下 28,583/28,583 次工具调用参数均 100% 正确还原，阻断或还原失败数为 0；同期 507 项工程回归测试全部通过。
- **统计显著性**：固定语料配对自助法（1,000 次重采样）测得 F1 提升的 95% 置信区间（百分点）：NVIDIA 回归集 [0.468, 0.595]、新增集 [0.440, 0.578]、中文正式 [2.502, 2.830]、中文聊天 [5.681, 6.503]、多语言金融 [0.217, 0.337]。

## 缓存加速实验

在人为给本地推理加锁 100 ms 的模拟负载下，每批发起 20 个命中缓存的请求，优化前后各跑 1,000 次：请求耗时 P50 从 108.07 ms 降到 10.76 ms，P99 从 115.96 ms 降到 21.28 ms；500 条公开文本的识别结果与缓存前完全一致。该实验用于验证缓存命中后能绕开推理锁，不代表真实并发下的总吞吐。
