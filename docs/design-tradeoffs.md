# 当前架构结论

| 模块 | 决定与边界 |
|---|---|
| Agent | 单个 Agent 持有当前工具；模型提出建议，确定性代码负责授权。配置/技能/工具通过端口注入。 |
| API | FastAPI 组合运行时；路由用公共依赖取服务，工作流不依赖具体 Agent 实现。 |
| 模型 | `core/llm.py` 统一工厂；按用途选择有序候选，保留合规过滤、失败切换、预算和整轮截止时间。同名 Agent 仅一个部署版本。 |
| 工具 | Schema 校验、超时、熔断、只读重试；写工具仅生成冻结申请，独立审批后由 worker 执行。MCP 只开放受控只读资料。 |
| 数据 | PostgreSQL + pgvector；本地/离线可用 SQLite。身份及租户条件由应用代码注入，路由巡检覆盖跨租户读写。 |
| 任务 | SQL 事件、outbox、租约/CAS、检查点；未知写结果先回查。事项成员显式授权，私聊记忆不进入共享上下文。 |
| 记忆 | Redis 工作记忆/回执，向量情景记忆、schema 5 画像；脱敏、准入、去重、过期及本人删除。当前业务事实从工具读取。 |
| 检索 | BM25 + 向量 + RRF；分词和 embedding 覆盖中英，按语料验证。向量缓存跟随集合版本，tenant 由代码注入。 |
| 前端 | React + Router + Query；可恢复 SSE/审批协议仍由现有控制器管理。切换身份清空私有查询缓存。 |
| 观测 | 持久回合、成本/工具错误/版本指纹；SLO 多窗口燃烧率与告警迟滞。归因只作诊断，不自动发布。 |

不保留 RLS、租户策略覆盖、应用内灰度/回滚、双人复标及强制线上样本发布门禁。原始评测中的未达标项仍保留，见 [评测数据](evaluation.md)。
