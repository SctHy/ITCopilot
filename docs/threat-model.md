# 安全边界

模型、用户文本、检索文档和工具返回均不提供权限。可信身份来自已验证令牌；开发令牌仅限显式开发环境。

| 风险 | 当前控制 | 保留边界 |
|---|---|---|
| 身份伪造 | OIDC 签名/issuer/audience/时效校验，忽略正文身份；吊销水位线即时拒绝旧令牌 | 身份提供者、管理员和部署密钥必须可信 |
| 跨租户/跨用户读取 | 应用注入 tenant，私聊按租户+用户；事项显式成员授权，每次读写重新检查 | 不依赖 RLS；新路由必须加入隔离巡检 |
| 模型越权写 | 参数校验、申请人确认、冻结哈希、独立审批、策略复核、执行审计 | 不把模型回答当作执行证据 |
| 重复/未知写 | 幂等键、租约/CAS、资源唯一索引、外部状态回查、漂移人工核对 | 无外部幂等接口时不能保证 exactly-once |
| 提示注入 | 工具权限独立于提示词；只读资料白名单；写操作必须走审批 | 单模型/单攻击评测不能证明全部攻击面安全 |
| 敏感信息 | 出站占位符、本地识别、存储/回复脱敏；工具参数恢复仅限受控边界 | 识别存在漏检；业务 ID 仍可发送；原始语音直接传 ASR |
| 审计篡改 | SQL 审计只追加，管理操作先写 started 再写结果；中断单独呈现 | 数据库超级用户和主机管理员不在防御边界内 |
| 资源滥用 | 身份/租户限流、整轮预算、请求截止时间、公平队列、附件限制 | 取消后上游仍可能继续处理/计费 |
| 历史与文件 | 本人删除、保留期限、附件授权/路径校验；证据恢复禁止越界路径及链接 | 不自动清理业务库；本机证据须另行备份 |

上线前配置真实 OIDC、替换演示凭据、限制数据库/Redis/管理入口、使用 TLS。不要把 `.env`、原始录音或凭据加入 Git、日志或评测报告。

验证入口：`tests/test_security_suite.py`、`scripts/evaluate_security.py`、`tests/test_tenant_isolation.py`、身份/审批/脱敏回归及专用服务集成。[历史安全数据](evaluation-public.md) 不代表生产验收。
