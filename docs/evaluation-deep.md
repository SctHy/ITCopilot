## 多轮稳定性

50 任务，2 种模拟用户各 3 遍；pass^k 指同一任务 k 次均成功。审批拆分修复后的最终配对：

| | flash 模拟：修复前 → 后 | pro 模拟：修复前 → 后 |
|---|---|---|
| 每遍通过 | 44/41/46 → 45/47/39 | 45/41/44 → 41/43/45 |
| pass^1 / pass^3 | 0.87 / 0.76 → 0.87 / 0.72 | 0.87 / 0.74 → 0.86 / 0.76 |
| **T3 pass^1 / pass^3** | **0.81 / 0.67 → 0.92 / 0.75** | **0.69 / 0.50 → 0.81 / 0.58** |

重复执行 7/300 → 0/300；T3 合计 54/72 → 62/72，Fisher p=0.14，不显著。总体 pass^1 基本不变，pass^3 一升一降。已知失败含角色误补、漏引用、模拟用户越界和模型超时；这些是当时观察，不能未经重测认定当前仍存在或已修复。
